# MiniMax H3: полный workflow ComfyUI и проверенные кейсы

Этот репозиторий сохраняет **полную схему AIHUB / MiniMax H3**, чтобы продолжить работу с другого компьютера. В ней есть генерация видео, создание фотокарусели, работа с масками, выбор звука, замена голоса и дополнительные обработки изображения.

**Workflow, или схема, — это соединённые между собой блоки в ComfyUI.** Каждый блок выполняет часть работы: загружает фото, запускает модель или сохраняет результат. На первом этапе не нужно разбираться во всех блоках: достаточно выбрать сценарий и заполнить его входы.

## 1. Общий workflow — основная схема проекта

Файл: [AIHUB-MiniMaxH3-PhotoCarousel-V2.json](workflows/AIHUB-MiniMaxH3-PhotoCarousel-V2.json).

В нём **270 блоков** и две большие ветки:

- **ВИДЕО:** с исходным видео или по фотографиям и тексту. Дополнительно можно использовать маску человека, выбрать оригинальный или сгенерированный звук, изменить голос, обработать картинку и добавить промежуточные кадры для плавности.
- **Photo Carousel:** сначала H3 создаёт последовательность кадров, затем схема выбирает из неё фотографии и обрабатывает их через FLUX. Результат — отдельные PNG.

В репозитории сохранены соединения, значения и режимы исходной схемы. Удалены только устаревшие облачные превью и часть состояния интерфейса. Фотографии, видео и веса моделей в JSON не находятся — их загружают отдельно.

**Что важно знать:** наличие схемы ещё не означает, что все её ветки готовы к запуску на чистом сервере. Например, для фотокарусели нужны дополнительные веса FLUX и LoRA из исходного экспорта; точные источники части файлов пока неизвестны. Для DLSS требуется отдельный компонент, помимо самой ноды. Это перечислено в [списке моделей](docs/MODELS.md).

## 2. Наши кейсы — отдельные упрощённые схемы

Это рабочие примеры, которые мы собрали и проверили отдельно. Они используют H3 и настройки из общей схемы, но **не заменяют её** и не доказывают работу всех её дополнительных функций.

| Кейс | Файл | Что получает схема | Результат |
|---|---|---|---|
| Перенос человека в видео | [CharacterSwap](workflows/H3-CharacterSwap-5090.json) | Фото человека + исходный ролик + описание | MP4 с оригинальным звуком |
| Тот же перенос с большим размером референсов | [CharacterSwap RefMax](workflows/H3-CharacterSwap-RefMax-5090.json) | Те же входы, `ref_image_size=max` | MP4 |
| Новое видео по фото и тексту | [PhotoText](workflows/H3-PhotoText-5090.json) | Одно фото внешности + описание новой сцены | MP4 с нативным звуком H3 |
| Видео, начинающееся с исходной фотографии | [OfficeSelfie FirstFrame](workflows/H3-OfficeSelfie-FirstFrame-5090.json) | Фото для первого кадра + описание движения | Ровно 10 секунд; отдельно сохраняется RAW |

В последнем кейсе исходное фото закреплено в H3 как первый кадр и дополнительно поставлено кадром №0 перед сохранением. Пользователь оценил этот тест в **10/10**. Подробности и ограничения сравнения: [журнал кейсов](docs/TESTED-CASES.md).

## Что уже проверено

На RTX 5090 32 ГБ успешно выполнены четыре прогона: EXP001, EXP002, PT001 и PT002. Для полной исходной схемы проверили наличие используемых типов нод в настроенном окружении; **все её ветки целиком не запускали**. Особенно это касается полной фотокарусели с исходными весами, DLSS, масок и замены голоса.

В `config/` записаны версии ComfyUI и нод, имена моделей и их контрольные суммы. Контрольная сумма позволяет убедиться, что скачан именно нужный файл, а не модель с похожим именем.

## Что не загружается в GitHub

Личные фотографии, исходные видео, полученные ролики, SSH-ключи, токены и сами модели. Для переноса наших материалов создан отдельный локальный архив. Как им пользоваться — в [руководстве по переезду](docs/MOVE-TO-ANOTHER-COMPUTER.md).

Подробная авторская справка из исходного JSON сохранена отдельно: [исходные заметки](docs/ORIGINAL-WORKFLOW-NOTES.md). Новый полный справочник «каждая нода и каждый переключатель» будет подготовлен следующим этапом по отдельной команде.
