# Установка на новой GPU-машине

Эта инструкция нужна, если вы арендуете **новый сервер** или разворачиваете окружение с нуля. Если меняется только ваш компьютер, а прежняя 5090 продолжает работать, начните с [переезда](MOVE-TO-ANOTHER-COMPUTER.md): повторная установка не нужна.

## Что потребуется

- NVIDIA GPU. Наша проверенная машина — RTX 5090 с 32 ГБ видеопамяти.
- Linux и Python **3.12** для повторения проверенного окружения.
- Git, `curl` и FFmpeg. FFmpeg читает и сохраняет видео. `aria2c` необязателен, но может ускорить загрузку больших весов.
- Примерно **62 ГБ** для основных H3-весов и дополнительное место для Python, нод, результатов и дополнительных моделей. Для новой установки разумно выделить не меньше 120 ГБ диска.
- Оперативная память: на проверенном сервере контейнеру было доступно около 187 ГБ. Мы не измеряли минимально достаточный объём. Checkpoint H3 около 40 ГБ больше видеопамяти 5090, поэтому часть весов находится в оперативной памяти.

Скрипты **не устанавливают и не меняют драйвер NVIDIA**. На 5090 нельзя брать старую сборку PyTorch без поддержки её архитектуры. Здесь фиксируется уже использованная версия PyTorch 2.10.0 с CUDA 13.0.

## 1. Скачайте этот репозиторий на сервер

После входа в GitHub:

```bash
gh repo clone porchax/minimax-h3-comfyui-workflows
cd minimax-h3-comfyui-workflows
```

Для закрытого репозитория нужна авторизация вашего GitHub-аккаунта. Пароли и токены не добавляйте в файлы проекта.

## 2. Сначала посмотрите план установки

```bash
python3.12 setup/install.py --comfy-dir /workspace/ComfyUI-H3 --profile full --dry-run
```

`--dry-run` только показывает, что будет установлено. Ничего не скачивается и не меняется.

`/workspace/ComfyUI-H3` — выбранная вами папка ComfyUI. Если в ней уже находится другая версия, скрипт остановится, чтобы не затереть её. Для новой установки используйте пустую папку.

## 3. Запустите установку полного набора нод

```bash
python3.12 setup/install.py --comfy-dir /workspace/ComfyUI-H3 --profile full
```

Скрипт:

1. Скачает записанную версию ComfyUI.
2. Скачает полный список пакетов нод исходной схемы на сохранённых версиях.
3. Создаст отдельное Python-окружение `.venv` внутри ComfyUI и установит зависимости.
4. Скопирует схемы в `ComfyUI-H3/user/default/workflows/`.
5. Скачает **основные H3-модели** и проверит их контрольные суммы.

Загрузка весов может занять заметное время. Скрипт умеет продолжать прерванную загрузку. Если готовый файл уже есть, он проверит его, а не будет скачивать ещё раз.

**Полный набор нод — не все дополнительные модели.** Для SAM3, Sapiens2, Seed-VC, FLUX, выбранных LoRA и DLSS-runtime нужны дополнительные файлы. Их список и статус находятся в [MODELS.md](MODELS.md). Неизвестные или непубличные веса скрипт случайными заменами не подменяет.

Если нужен только наш набор проверенных кейсов, используйте более компактный профиль:

```bash
python3.12 setup/install.py --comfy-dir /workspace/ComfyUI-H3 --profile tested
```

В нём устанавливаются H3 и два пакета, нужные нашим кейсам: VideoHelperSuite для видео и RES4LYF для расписания `beta57`. Большую исходную схему с этим профилем запускать нельзя без установки остальных нод.

## 4. Запустите ComfyUI

Для новой самостоятельной установки:

```bash
python3.12 setup/start.py --comfy-dir /workspace/ComfyUI-H3 --port 8188
```

Оставьте это окно терминала открытым: в нём работает ComfyUI. Сервер принимает соединения только через свой `localhost`; для доступа с другого компьютера используется SSH-туннель.

На своём компьютере откройте отдельный терминал:

```bash
ssh -p SSH_PORT -N -L 8188:127.0.0.1:8188 root@SSH_HOST
```

Замените `SSH_PORT` и `SSH_HOST` на значения из вашей аренды. Затем откройте в браузере `http://localhost:8188`.

### Если это готовый образ ComfyUI на Vast.ai

В нашем образе ComfyUI уже управляется сервисом Supervisor и работает на внутреннем порту **18188**. Не запускайте второй ComfyUI на занятом порту и не меняйте настройки портала ради этой инструкции. Для существующего сервиса используются его Python `/venv/main/bin/python`, рабочая папка `/workspace/ComfyUI` и команда:

```bash
supervisorctl restart comfyui
```

Скрипту установки можно передать существующий Python через `--python /venv/main/bin/python`, но только если вы намеренно устанавливаете пакеты именно в это окружение. Существующие Git-каталоги с другой версией или локальными изменениями скрипт не перезаписывает.

## 5. Проверьте установку без генерации

На компьютере, где открыт туннель:

```bash
python3 setup/check.py --url http://127.0.0.1:8188 --include-original
```

Проверка ищет повреждённые соединения в схемах, отсутствующие типы нод и расписание `beta57`. Она **не запускает генерацию**, не проверяет наличие каждого дополнительного веса и не подтверждает работоспособность DLSS-runtime.

Проверить основные модели отдельно:

```bash
python3.12 setup/install.py --comfy-dir /workspace/ComfyUI-H3 --verify-models
```

Проверка читает большие файлы с диска и может занять время.

## Какие версии сохранены

| Компонент | Проверенная версия |
|---|---|
| ComfyUI | 0.43.0, точный commit в `config/repositories.json` |
| Python | 3.12 |
| PyTorch | 2.10.0 + CUDA 13.0 |
| torchvision / torchaudio | 0.25.0 / 2.10.0 |
| Модели | Точные ревизии и SHA256 в `config/models.json` |
| Пакеты нод | 19 репозиториев с точными commit в `config/repositories.json` |

`config/environment-observed.txt` — снимок пакетов с нашего рабочего сервера для справки. Не устанавливайте его целиком вслепую на другой компьютер: там есть пакеты для конкретной платформы и дополнительные инструменты.

Исходное окружение проходило реальные генерации. Установщик проверяется отдельно; полная новая установка с нуля не является автоматически повторным тестом всех возможностей исходной схемы.
