# Переезд на другой компьютер

## Если остаётся та же арендованная 5090

Это самый простой случай. На сервере уже находятся ComfyUI, модели, ноды и загруженные материалы. **Смена вашего компьютера не удаляет их с сервера.**

1. Войдите на новом компьютере в свой аккаунт GitHub.
2. Скачайте этот закрытый репозиторий. Через GitHub можно выбрать **Code → Download ZIP**, либо использовать `gh repo clone porchax/minimax-h3-comfyui-workflows` после `gh auth login`.
3. Откройте ту же аренду в Vast.ai и её портал ComfyUI. Если используете SSH, настройте туннель ниже.
4. Откройте нужную схему в ComfyUI и продолжайте работу. Ещё раз запускать установку моделей не требуется.

## Подключение через SSH

На новом компьютере нужен SSH-ключ, который разрешён для подключения к вашей аренде. Скопируйте свой существующий ключ безопасным способом либо настройте новый доступ через Vast.ai. **Ключа в GitHub и в нашем архиве материалов нет.**

В терминале:

```bash
ssh -i PATH_TO_YOUR_KEY -p SSH_PORT -N -L 8188:127.0.0.1:18188 root@SSH_HOST
```

Замените:

- `PATH_TO_YOUR_KEY` — путь к вашему SSH-ключу;
- `SSH_PORT` и `SSH_HOST` — порт и адрес из команды подключения Vast.ai.

Не закрывайте окно команды. Откройте **http://localhost:8188** в браузере. Во встроенном образе нашей аренды ComfyUI слушает порт **18188**, а первоначальный порт **8080** относится к Jupyter.

Если вы ставили самостоятельный ComfyUI по инструкции установки и выбрали серверный порт 8188, последний порт в туннеле тоже будет 8188: `-L 8188:127.0.0.1:8188`.

## Что забрать с прежнего компьютера

Репозиторий содержит схемы, версии и инструкции. Личные фотографии и видео туда не загружаются.

Для них рядом с проектом создаётся архив **`transfer/minimax-h3-private-transfer.tar.gz`**. Скопируйте его на новый компьютер отдельно, например через собственный диск или локальный перенос. Это приватный архив: в нём есть личные изображения и результаты генераций.

Внутри:

- `input/` — исходные фотографии и ролики под именами, выбранными в наших схемах;
- `results/` — готовые видео и сравнения;
- `experiments/` — точные графы, промпты, записи, оценки и вспомогательные материалы;
- `session/` — сохранённые схемы, заметки, снимки окружения и параметры подключения без ключа;
- `MEDIA-MANIFEST.json` — соответствие исходных и переносимых имён, размеры и контрольные суммы.

Имена внутри архива сделаны пригодными и для Windows: в именах входных файлов нет двоеточий. Оригинальные имена, например `IMAGE 2026-10-29 15:27:05.jpg`, записаны в манифесте. В старых записях экспериментов они могут встречаться как исторические имена — это нормально.

Самый простой способ распаковать — архиватор. В терминале macOS/Linux:

```bash
mkdir -p h3-private
tar -xzf minimax-h3-private-transfer.tar.gz -C h3-private
```

Рядом с архивом есть файл `.sha256`: он позволяет проверить целостность переноса. Веса моделей в этот архив не входят; они остаются на 5090 или скачиваются заново по манифесту.

## Если аренда тоже меняется

Следуйте [установке на новом сервере](INSTALL.md), затем загрузите содержимое `input/` через интерфейс ComfyUI или скопируйте в `ComfyUI/input/`. Готовые результаты можно хранить локально — загружать их на сервер для работы не обязательно.

Не путайте остановку и удаление аренды. У нашего экземпляра нет постоянного host volume: stop/start сохраняет файловую систему, а recycle/destroy её удаляет. Перед удалением сервера сначала сохраните всё нужное вне него.
