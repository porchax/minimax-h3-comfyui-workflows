# Возможности полного workflow

Это обзор **всей исходной схемы**, а не только наших тестов. Основной файл — [AIHUB-MiniMaxH3-PhotoCarousel-V2.json](../workflows/AIHUB-MiniMaxH3-PhotoCarousel-V2.json).

## Как ориентироваться

Схема большая, поэтому уменьшите масштаб, найдите блок **«ВИДЕО ↔ ФОТО · ПОЛНОЕ ОТКЛЮЧЕНИЕ ВЕТКИ»** и начните с него. Это главный выбор: вы хотите видео или набор фотографий.

После выбора большой ветки выберите источник внутри неё. Источник — это материал, от которого строится результат: исходное видео либо фотографии и ваше описание. Две альтернативные группы входов одновременно включать не нужно.

Если ищете нужный блок по справке, числа вида **№1281** — его сохранённый номер в JSON. Название и номер помогают найти его; сами числа вводить никуда не требуется.

## Карта возможностей

| Возможность | Что нужно дать схеме | Что она делает |
|---|---|---|
| Видео с видеореференсом | Исходный ролик, фото, описание ролей материалов | Создаёт новое видео с опорой на исходные действия и сцену |
| Видео без видеореференса | Фото и описание действия | Придумывает движение, камеру и сцену по тексту |
| Маска человека | Исходный ролик и модель SAM3 или Sapiens2 | Выделяет область человека для подготовки видеореференса |
| Нативный звук H3 | Описание желаемого звука | Генерирует звук вместе с видео |
| Оригинальный звук | Исходное видео со звуковой дорожкой | Использует звук исходного ролика в финальной сборке |
| Управление звуком T8 | Оригинальная дорожка, видео и включение T8 | Дополнительно управляет аудиолатентом H3; это не гарантия идеального липсинка |
| Замена голоса Seed-VC | Дорожка и образец нужного голоса | Преобразует выбранную дорожку после генерации |
| DLSS-обработка | Сгенерированное видео и установленный runtime | Дополнительно обрабатывает изображение |
| DLSS-интерполяция | Видео и runtime | Добавляет промежуточные кадры для большей плавности |
| NVIDIA VSR | Кадры видео и NVIDIA VFX | Дополнительный вариант увеличения/обработки изображения |
| Фотокарусель из видео | Видео и фото-референсы | Создаёт H3-последовательность, выбирает кадры и обрабатывает их через FLUX |
| Фотокарусель без видео | Фото, описание поз и сцены | Строит последовательность по тексту, затем сохраняет выбранные фотографии |

## Сценарий A: видео с исходным роликом

1. В главном переключателе **№1281** выберите **ВИДЕО**.
2. В выборе источника **№1493** включите **«ВИДЕОРЕФЕРЕНС + МАСКИ»**. Это имя входной группы; саму маску включают отдельно.
3. Загрузите исходный ролик в **№1011**.
4. Загрузите фотографии в блоки **Picture 1, Picture 2…**. Первый блок — **№137**. Остальные фотографии добавляйте по необходимости.
5. В **«Основной промпт», №1003** опишите, какое фото задаёт лицо, а какое — одежду или другие детали. Движение и сцену обычно задаёт видео.
6. Согласуйте длину ролика с полем длительности **№132**: в полной схеме оно отдельно от длины загруженного видео.
7. Для результата с оригинальным звуком выберите **3** в **№1215** и выключите замену голоса Seed-VC.
8. Результат сохраняет **№1332**, `VHS_VideoCombine`. По умолчанию ищите MP4 с началом имени `MiniMax` в `ComfyUI/output/`.

H3 создаёт кадры заново. Просьба «сохранить фон» в тексте не означает, что фон останется неизменным пиксель в пиксель.

## Сценарий B: видео по фото и описанию

1. Главный выбор — **ВИДЕО**.
2. В **№1493** выберите **«ПРОМПТ БЕЗ ВИДЕО»**.
3. Загрузите фото в Picture-блоки, заполните **№1003**.
4. Опишите сцену, действие и камеру: исходного ролика здесь нет, модель должна получить эти сведения из текста.
5. Не оставляйте в промпте ссылки на `<Video 1>` или `<Audio 1>`, если таких материалов нет.
6. Выберите **2 = H3** для нативного звука. Результат снова сохраняется в **№1332**.

Фото здесь служат **референсами**: показывают модели внешность. Это не то же самое, что жёстко задать фотографию первым кадром. Проверенный нами вариант с закреплённым первым кадром вынесен в отдельную схему [FirstFrame](../workflows/H3-OfficeSelfie-FirstFrame-5090.json).

## Сценарий C: фотокарусель с видеореференсом

1. В главном переключателе выберите **Minimax Photo Carousel**.
2. Внутри карусели, в **№1537**, выберите **«ВИДЕОРЕФЕРЕНС»**.
3. Видео загружается в **№1383**.
4. Фото загружаются в **№1333–1336**, дополнительное лицо — **№1405**. В исходном примере этим фото назначены разные роли: человек, фон, одежда и дополнительный референс. При замене материалов обновите роли в тексте.
5. Описание фотосерии находится в **PHOTO · ПРОМПТ, №1337**.
6. В **№1527** задайте, сколько фотографий хотите получить.
7. H3 создаёт последовательность, **№1354** выбирает из неё кадры, FLUX обрабатывает их по одному. Готовые PNG сохраняет **№1531**, `SaveImage`, в `ComfyUI/output/`.

Количество фотографий — не длительность генерации. Например, «12 фото» не означает «12 секунд».

## Сценарий D: фотокарусель по фото и тексту

Выберите **Photo Carousel**, затем **«ПРОМПТ БЕЗ ВИДЕО»** в **№1537**. Загрузите фото и заполните **№1337**. Длительность H3-последовательности задаёт **№1539**, количество сохраняемых фотографий — **№1527**. Позы, смену ракурсов, одежду и окружение опишите в тексте.

Дальнейший путь тот же: H3 → отбор кадров → FLUX → цвет и зерно → PNG. Для полного повторения нужны исходные FLUX-веса и LoRA, перечисленные в [моделях](MODELS.md). Сейчас этот сценарий не следует считать готовым «из коробки».

## Дополнительные обработки: когда включать

| Блок | Где включить | На что обратить внимание |
|---|---|---|
| Маска | **№1497**, выбор SAM3/Sapiens2 — **№1261** | `false` = SAM3, `true` = Sapiens2. Нужны соответствующие веса |
| T8 | **№1481**, дополнительно условия звука в схеме | Работает с оригинальным звуком при видеореференсе. Проверяйте также параметры самой T8-ноды **№1162** |
| Seed-VC | **№1424** | `false` = оставить выбранный звук, `true` = взять результат замены голоса. Образец голоса загружается в **№1423** |
| DLSS-картинка | **№1293** | Нужны Python-нода и отдельный NVIDIA/Wine runtime |
| DLSS-плавность | **№1304** | `2x` значит удвоение частоты: 24→48, 30→60. Это не всегда именно 48 FPS |
| NVIDIA VSR | **№921** | Отдельный резервный вариант обработки, GPU/runtime проверяются отдельно |

Маска в этом JSON смешивает исходное и инвертированное по цвету изображение в выбранной области. Она готовит видеореференс, а не вырезает готовое лицо для окончательного монтажа. Seed-VC получает выбранную звуковую дорожку целиком: эта ветка не выделяет речь из музыки автоматически.

Для первого запуска дополнительные обработки лучше отключить. После рабочего короткого примера включайте по одной: так видно, какая именно обработка дала изменение или ошибку.

## Что мы ещё не подтвердили

Полная фотокарусель с её исходными FLUX/LoRA, качество масок, T8, Seed-VC, DLSS и VSR не проходили у нас полную оценку готового результата. Это сохранённые возможности схемы, а не перечень успешно протестированных функций. Фактические проверки описаны отдельно в [кейсах](TESTED-CASES.md).

В исходной фотокарусели также отмечены деление на ноль в **№1521** и цепочка PreviewAudio после изображений. Эти места нужно исправлять отдельно при вводе фотокарусели в работу; в этой публикации соединения исходной схемы не менялись.
