# Первый запуск: от своих материалов до результата

## 1. Откройте ComfyUI

Если 5090 уже настроена, **не нужно заново скачивать модели из-за смены компьютера**. Откройте ComfyUI на том же сервере. Способы подключения описаны в [переезде](MOVE-TO-ANOTHER-COMPUTER.md).

Если сервер новый — сначала выполните [установку](INSTALL.md).

## 2. Откройте нужную схему

Скачайте JSON из папки `workflows/` и перетащите его в окно ComfyUI. Можно также использовать меню открытия workflow. JSON — это файл схемы, а не модель и не видео.

Для общего workflow откройте **`AIHUB-MiniMaxH3-PhotoCarousel-V2.json`**. Для повторения конкретного нашего теста откройте файл из [раздела кейсов](TESTED-CASES.md).

Если ComfyUI сообщает `Missing Nodes`, это означает, что на сервере не установлен один из нужных блоков. Не нужно заменять его случайным похожим блоком: установите пакет из списка [нод](INSTALL.md), перезапустите сервер и обновите страницу.

## 3. Подготовьте выбранную ветку общего workflow

Сначала выберите **ВИДЕО** или **Photo Carousel** главным переключателем. Затем внутри выбранной ветки включите один источник: видео либо промпт без видео. Подробные пути для четырёх сценариев — в [обзоре возможностей](FULL-WORKFLOW.md).

Для первого видео берите короткий фрагмент около пяти секунд. Отключите маску, T8, Seed-VC, DLSS и VSR. Это помогает сначала проверить саму генерацию, а дополнительные эффекты проверять позже.

В исходном файле сохранены старые названия облачных материалов. До нажатия «Запустить» их нужно заменить своими файлами. Выключите неиспользуемые Picture-группы; проверьте, что реально подключены только нужные фотографии.

Для видеоветви это можно сделать через панель Picture-групп **№719**: оставьте используемые фотографии, ненужные группы обойдите. В исходнике также есть три дополнительных LoRA-загрузчика **№1128, №1129 и №1123** с силой 0. Если соответствующих файлов нет, обойдите эти загрузчики через `Bypass`; одной нулевой силы может быть недостаточно. Это уже будет ваш локальный вариант исходной схемы — сохраните его под новым именем, чтобы авторский JSON остался под рукой.

## 4. Загрузите фото и видео

- **LoadImage / Загрузить изображение:** нажмите кнопку выбора или загрузки файла в нужном Picture-блоке.
- **VHS_LoadVideo:** нажмите `choose video to upload`, выберите исходный ролик.
- **LoadAudio / Загрузить аудио:** используется, если выбранный сценарий просит отдельный звук или образец голоса.

У файла может быть любое имя. Названия вроде `character-beanie.jpg` — это имена из наших тестов. После загрузки вашего файла убедитесь, что именно он выбран в поле ноды.

На сервере загруженные материалы обычно лежат в **`ComfyUI/input/`**. Фото на вашем компьютере не становится доступным серверу, пока вы его не загрузили или не скопировали туда.

Для лица лучше отдельные понятные портреты. В промпте подпишите роли: `<Picture 1>` — главное лицо; `<Picture 2>` — дополнительный ракурс и так далее. Эти номера соответствуют порядку подключений в H3, а не названию файла.

## 5. Проверьте модели

В загрузчиках моделей должны быть выбраны реально скачанные файлы. Основная H3-модель лежит в `models/diffusion_models/`, текстовый энкодер — в `models/text_encoders/`, VAE — в `models/vae/`. VAE — это компонент, который переводит изображение в представление модели и обратно; отдельно управлять его работой на первом запуске не нужно.

Если не хватает LoRA, возможны два пути: получить именно нужный файл либо **обойти его загрузчик**. LoRA — дополнительная настройка модели, обычно под стиль или определённые свойства изображения. Значение силы `0` не всегда отменяет проверку наличия файла. В ComfyUI обход называется `Bypass`; в стандартном интерфейсе его можно выбрать в меню ноды. При обходе схема меняется относительно авторского результата — запишите это в журнал.

Не скачивайте файл с похожим названием и не переименовывайте его в нужное имя. Перечень точных файлов и недостающих источников находится в [MODELS.md](MODELS.md).

## 6. Напишите понятный промпт

Промпт — это текст задания для модели. В полной видеосхеме он находится в **№1003**, в фотокарусели — в **№1337**.

Опишите:

1. Кто должен быть в кадре и откуда берётся его внешность.
2. Что он делает.
3. Как выглядит сцена и как движется камера.
4. Что сохранить из исходного видео, если оно есть.
5. Какой нужен звук.

Пример смысла: «Лицо и волосы взять из Picture 1. Движения, одежду, камеру и помещение сохранить из Video 1. Оригинальный звук оставить». Готовые английские промпты наших кейсов лежат в `prompts/`; обязательно меняйте описание человека и материалов под свои входы.

Если исходного видео нет, не ссылайтесь в тексте на Video 1. Фото как референс внешности и фото как первый кадр — разные способы работы. Для второго используйте отдельный кейс FirstFrame.

## 7. Запустите и дождитесь файла

Нажмите **«Запустить» / Run / Queue**. Модель сначала готовит входы, затем генерирует, декодирует кадры и сохраняет результат. Завершение счётчика шагов — ещё не завершение всей задачи.

Быстрое TAEH3-превью может отличаться от готового видео. Оценивайте скачанный MP4 или PNG, а не только картинку предпросмотра.

## 8. Где забирать результат

| Сценарий | Блок сохранения | Файлы на сервере |
|---|---|---|
| Полная схема, ветка ВИДЕО | **№1332**, `VHS_VideoCombine` | `ComfyUI/output/`, имя начинается с `MiniMax` |
| Полная схема, Photo Carousel | **№1531**, `SaveImage` | `ComfyUI/output/`, PNG; в экспорте префикс `1` |
| Наш CharacterSwap | `SaveVideo` | `ComfyUI/output/video/` |
| Наш PhotoText | `SaveVideo` | `ComfyUI/output/video/photo-text/` |
| Наш FirstFrame | Финальный `SaveVideo` и отдельный RAW | `ComfyUI/output/video/photo-text/` |

Точный путь зависит от `filename_prefix` в блоке сохранения. Например, `video/my_test` создаёт результат в подпапке `output/video/`. ComfyUI добавляет номер, чтобы очередной запуск не затёр предыдущий.

Файл можно скачать из превью блока сохранения или из истории выполненных задач. Папка `results/` в нашем локальном проекте — отдельное место, куда мы скачивали копии; ComfyUI сам туда не пишет.

В FirstFrame основной файл начинается с **`PT002_OfficeSelfie_Chaos_10s`**. Файл **`PT002_RAW_243frames`** — сохранённая исходная генерация до подстановки фото в кадр №0 и обрезки до десяти секунд.

## 9. Запишите результат теста

Сохраните схему, полный промпт, имена входных файлов, seed, размер, длительность и время генерации. Seed — число, позволяющее повторять начальные случайные условия. Оно помогает сравнивать тесты, хотя само по себе не гарантирует одинаковые результаты при другом окружении.

Оценивайте отдельно сходство лица, стабильность при движении и выполнение сюжета. У нас PT001 получил 5/10 без улыбки и 8/10 с улыбкой — один средний балл скрыл бы эту разницу.

## Если что-то не работает

| Что видно | Что проверить сначала |
|---|---|
| `Missing Nodes` | Установлены ли пакеты нод; перезапущен ли ComfyUI |
| Модель не найдена | Скачан ли точный файл и выбран ли он в загрузчике |
| Фото/видео не найдено | Файл загружен на сервер и выбран в нужной ноде |
| Ошибка LoRA при силе 0 | Файл всё равно может требоваться; получите его или обойдите загрузчик |
| Ошибка при включении DLSS | Установлен ли его отдельный runtime, а не только Python-нода |
| Закончилась видеопамять | Уменьшите размер/длительность и число референсов; отключите дополнительные обработки |
| Видео есть, а MP4 ещё не появился | Дождитесь окончания декодирования и сохранения |
| Фотокарусель падает в служебной цепочке | Проверьте известные проблемы исходного файла в [обзоре](FULL-WORKFLOW.md) |
